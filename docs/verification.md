# Проверка сервиса

7 ноября 2026 года, OpenJDK 17.0.21, Maven 3.9.9, PostgreSQL 16.4.

`./mvnw -Pintegration clean verify` собрал исполняемый JAR. Все 48 тестов прошли, пропущенных нет.

| MetricCalculatorTest | 5 | Формулы, округление, пустое подразделение, направление изменения |

## Запуск JAR

HTTP-ответы по демопрогонам сверены с JSON-примерами в `docs/`. Для HQ во втором прогоне получено 11 проблем, из них 4 новых и 7 сохраняющихся. Исправлено 5 проблем прошлого прогона. Повторный запуск приложения с той же базой данных сохранил оба результата и даты создания.

Некорректные даты вернули 422. Прогон за 9 ноября на тех же данных завершился с 11 сохраняющимися проблемами. Отдельно проверены ручные команды Maven-плагина Liquibase для полного отката и повторного наката после создания прогонов.
