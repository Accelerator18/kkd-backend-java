# Мотивация участия в проекте

## Почему мне интересен проект

Мне интересно разрабатывать backend, в котором результат можно проверить на конкретных
данных и использовать в работе. Здесь недостаточно просто вернуть записи из базы:
нужно правильно определить нарушения, учесть иерархию подразделений и объяснить,
что изменилось между проверками.

На стажировке в прошлой Фабрике решений я работал с Python backend: расчётным модулем, API и подключением
к базе данных. Хочу применить этот опыт к сервису на Java и глубже разобраться
в Spring Boot, PostgreSQL и управлении миграциями. Задача ККД привлекает сочетанием
бизнес-логики и инженерной работы: ошибка в расчёте дельты или метрики напрямую влияет
на то, какие решения примет пользователь.

## Как вижу свою роль в команде

Вижу себя backend-разработчиком: уточнять правила вместе с аналитиком, проектировать
схему данных, реализовывать расчёты и REST API, писать тесты и участвовать в ревью.
Готов согласовывать контракт с frontend-разработчиком и помогать с запуском сервиса
в Docker и проверками в CI. Мне важно понимать весь путь данных  от записи цели
до метрики, которую видит руководитель.
